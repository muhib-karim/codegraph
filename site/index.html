Ask who calls what. Get file:line answers.

codegraph parses Python, Java, TypeScript and JavaScript with Tree-sitter, resolves names into an embedded graph database and answers callers, callees, impact and search for people and coding agents. Every result is a symbol plus a citation you can open. No LLM sits in the answer path.

pip install "codegraph[mcp] @ git+https://github.com/muhib-karim/codegraph"

Python 3.11 or 3.12 · MIT licence · indexing never executes repository code

    Quickstart

    1. Install into a virtual environment (Python 3.11+).
      python3 -m venv .venv && . .venv/bin/activate
pip install "codegraph[mcp] @ git+https://github.com/muhib-karim/codegraph"
    2. Index a repository. The graph lands in .codegraph/ inside it.
      codegraph index path/to/repo
    3. Ask. Rows are tab-separated: citation, symbol, kind, confidence, then depth or the definition.

    exact means a static binding under the resolver's rules; heuristic marks a unique-name guess for an untyped receiver. Neither proves runtime behaviour.

    Give your coding agent the graph

    codegraph mcp serves the index read-only over stdio with the official MCP SDK. Paths outside the indexed repository are refused, responses are paged, and every row keeps its citation and confidence.

    Claude Code

    claude mcp add codegraph -- /abs/.venv/bin/codegraph mcp --repo /abs/repo

    Codex CLI · ~/.codex/config.toml

    [mcp_servers.codegraph]
command = "/abs/.venv/bin/codegraph"
args = ["mcp", "--repo", "/abs/repo"]
    search
    symbols by name substring, exact matches first
    callers
    incoming calls and value references
    callees
    direct outgoing calls with target definitions
    impact
    what a change to a symbol or file can reach
    find_symbol
    definitions for a name or full id
    inherits
    descendants or ancestors
    dead_code
    unused candidates, never proof
    index_status
    coverage and staleness by SHA-256
