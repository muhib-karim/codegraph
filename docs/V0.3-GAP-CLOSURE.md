# v0.3 local explorer gap closure

This branch is based on v0.2 main `43dcba2b0025c68cd738717331d8a97876231621`. It changes only the packaged frontend and its browser contract test. The CLI, indexer, graph schema, query adapter and read-only server stay unchanged.

- Query status is a short, stable polite live region, separate from result rows. The source dialog has its own visually hidden polite loading/success/error status. This reduces the chance of announcing an entire result list as one status update. The source dialog's existing focus and Escape return behavior remain.
- Local URL hash now records selected file/symbol, command, target, depth, path scope, ancestor toggle, dead-code kind/confidence and whether a query has run. Back/forward and a copied URL restore those controls and rerun the bounded query; browsing a file does not silently replace a previously run query's target.
- A real browser fixture probes literal HTML-like source content and long Unicode symbol text. It checks no injected image or global marker and records requests and pixels. This is a sampled browser test, not an exhaustive XSS or WCAG certificate.

Limits unchanged: one-hop graph slice, dense mobile canvas with list fallback, read-only loopback service, no live indexing, the pre-existing source realpath TOCTOU window against a local malicious writer, and no unsupported language inference. The deferred accessibility work is bounded to reliable names and status updates, not a claim of full screen-reader conformance. Before promotion, verify in at least one real assistive-technology/browser pairing if formal accessibility certification is required.
